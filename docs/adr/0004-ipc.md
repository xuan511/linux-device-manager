# ADR 0004: Unix Domain Socket IPC

## Context

The daemon must be the sole serial owner while local tools issue commands and
observe status without requiring root or exposing a network service.

## Decision

Use an `AF_UNIX` stream socket with a length-bounded request/response protocol.

## Alternatives

TCP exposes unnecessary network surface. D-Bus adds a dependency and hides IPC
mechanics. Shared memory complicates framing, notification, and crash recovery.

## Consequences

Socket path permissions form the trust boundary. Clients must handle partial
I/O, peer closure, bounded message sizes, and daemon restart.

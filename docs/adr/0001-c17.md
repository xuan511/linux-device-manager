# ADR 0001: C17 for Host Software

## Context

The project teaches Linux systems programming and must share protocol code with
small embedded targets while retaining modern language guarantees.

## Decision

Use C17 with required conformance and no compiler extensions in portable layers.

## Alternatives

C11 lacks no capability we need but C17 incorporates defect fixes. C++ would add
language/runtime surface that distracts from the Linux C learning goal.

## Consequences

Ownership and cleanup remain explicit. CI must test GCC and Clang diagnostics.
